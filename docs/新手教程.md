# 新手教程：小财务每天怎么用（小白版）

> 这本账就是三件事：**谁欠我钱**、**我欠谁钱**、**手里还剩多少钱**。
> 你每天要做的，就是把「今天发生的事」记进去，别攒着。
> 全篇不需要懂会计，照着一行一行点就行。

---

## 〇、先认清屏幕

打开小程序，最上面一排四个大字，是整个系统的骨架：

| 顶上一排 | 里面是什么 | 你多久用一次 |
|---|---|---|
| **工作台** | 首页：今天要做的事、四个大数字、钱够不够、一句话记账、🔎 找功能 | 每天开手机先看这里 |
| **记账** | 应收 / 应付 / 支出 / 导入（四个小页签） | 每天，记东西都在这里 |
| **报表** | 利润表、家底、历史、流水；**往下滑还有**：数据体检、导出 Excel、云端备份、🔑 找回口令、功能模块、员工账号、月底收尾、回收站、操作日志 | 每月一次，和偶尔要「管一管」的时候 |
| **设置** | 单位（账期 / 档案 / 合同价）、账户与期初余额、分类、账套、开账向导、账本封存 | 第一次用，之后很少 |

> 记住一句话：**「记账」里填数，「报表」里看数和管系统，「设置」里配单位和账户。**
>
> 🔎 **找不到某个按钮时**：回工作台，点 **🔎 找功能**，输两个字（比如「备份」「体检」「核销」），点一下直接跳过去。不用记它藏在哪个页签。

## 一、第一次用：3 分钟开好账（只做一次）

### 1. 设口令

第一次打开会让你设一个**老板口令**（至少 4 位）。

设完会弹出 **16 位恢复码**，形如 `PH4D-LWDJ-WLPL-KG4H`。

> ⚠️ **立刻抄在纸上，贴在抽屉里。** 这个码只显示一次，我们后台也不存。
> 忘了口令只能靠它自己重设，没有它就是进不去。

### 2. 一屏填完底数

首页上面有个卡片「开账引导（照着填几步就能用）」，点 **⚡ 一屏填完（推荐，30 秒）**，里面四块：

1. **账户余额** —— 现在手上多少钱：现金多少、银行卡多少、微信多少。填「现在剩多少」，不是流水。
2. **默认账期** —— 一般填 `30`（意思是开单后 30 天该收钱）。填了以后开单可以不管收款日，系统自己算。
3. **期初应收** —— **别人现在欠我多少**。一行一家，写成 `张老板 12000`，一行一个。
4. **期初应付** —— **我现在欠别人多少**。写成 `某某化工厂 8600`。

填完点「保存，开始记账」。点了两次也不会翻倍（余额是「设」不是「加」）。

> **也可以整本填**：**记账 → 导入 → 📦 开账全套（新建账套一次装好）** → 点「下」下载一本 7 个页签的表
> （账户期初 / 默认账期 / 期初应收 / 期初应付 / 期初借支 / 期初借款，第一页是说明），
> 填完点「传」一次上传，**一页签对应一块，一起进去**。好处是开账那份数你自己留了底，
> 以后想核「当初期初是多少」直接翻这个文件；坏处是要先下载。两种方式随便挑一种，别两边都填。

> 账本还是空的、不知道分类怎么建？**设置**（最下面）→ **🧱 新账本模板（空账本一次配好）**，选「生产加工（最常见）」一键配好分类和账户。

### 3. 把用不上的关掉

**报表** → 往下滑 → **🧩 功能模块（用不上的关掉）**。

比如厂里不按件算工资，就关「计件工资」——界面立刻清爽，少一半按钮。

> 应收、应付、支出报销、Excel 导入这四块是地基，关不掉，也不用关。

### 4. 要用的人多的话（可选）

**报表 → 👤 员工账号（一人一个口令）**：一个人一行，勾上他能看的模块，存一下。

- 员工用他自己的口令进来，只看到自己该看的；
- 他看不到金额类的东西（单价、毛利、外协费、返工损失）；
- 他能记账、收款，但**改单、删单、看报表要老板口令**。

## 二、每天必做：5 分钟三条动线

> **先把这套用法记住：一个人管账，就维护两本表。**
>
> | 哪本 | 什么时候用 | 里面有哪几页 |
> |---|---|---|
> | **📦 开账全套** | 只有**新建账套**时填一次 | 账户期初 · 默认账期 · 期初应收 · 期初应付 · 期初借支 · 期初借款 |
> | **📦 日常台账** | **每天/每几天**填一次，一次传完 | 应收对账 · 应付对账 · 支出 · 借支 · 报销 · 付房东 |
>
> 两本都在 **记账 → 导入** 最上面，「下」是下载空表，「传」是填完上传。
> 日常那本**空着的页签不用管**（系统会显示「没填，跳过」），所以做法是：
> 每天早上打开同一个文件，把昨天发生的几件事分别填到对应页签，攒够一次上传——
> 不用再一个个选类型、一个个传文件。


### 动线 A：对方发来对账单 → 导进来（最重要）

你的客户、供应商每月（或每天）会给你一个数：**「这个月你欠我 8600」**。不要一笔笔去凑，直接导。

1. 点 **记账 → 导入**
2. 最上面「📋 每天要用的模板」，找到那一行（**要一次传几样，就直接用最上面的 📦 日常台账**，下面这张表是单样传的时候对照用）：

| 你要记什么 | 用哪一行 | 表格里填什么 |
|---|---|---|
| 客户这个月该给我多少（按对账金额） | **应收对账（按客户对账金额）** | 客户, 对账金额, 月份 |
| 我欠供应商/外发厂多少（按对账金额） | **应付对账（按供应商/外发）** | 供应商, 对账金额, 分类, 月份 |
| 一单一单的活 | **应收（按单）** | 客户, 产品, 金额, 成本, 到期日 |
| 一单一单的进货 | **应付（按单）** | 供应商, 分类(选硫酸/染料/外发加工费…), 金额 |
| 付房东的租金、押金、水电 | **付房东（租金/押金/水电）** | 名称, 金额, 月数(押金填 0), 分类, 起始日 |

3. 点右边的 **「下」** 下载模板（Excel，第 2 列带下拉选项，不用记分类名）
4. 填完，点同一行的 **「传」**，选文件，先看预览，再点「确认导入」

**三个关键规矩：**

- **一个月一家一条**。不要一天导一条，也不要一笔一笔凑——就按对方对账单那个总数记。
- **同一份表传两遍不会翻倍**（同客户 + 同金额 + 同月份会被拦下）。
- **月份留空 = 记到这个月**。想补上个月就写 `2026-10` 或 `10月`，系统会记到那个月最后一天。

### 动线 B：收钱（客户给钱了）

**在哪找**：工作台点 **💰 收钱** → 直接跳到「还没结清的应收」，谁欠多少一目了然。

一张单子的四个按钮，区别很大，别点错：

| 按钮 | 用在什么时候 | 会发生什么 |
|---|---|---|
| **收款** | 客户给了一部分（比如欠 5000 给了 3000） | 弹框填金额，可写 `3000,07-05`（金额,日期）。**不填就按「一次收清」** |
| **收清** | 客户把这张单一次付完 | 一键收满，不用填数 |
| **整户收款** | 一个客户打了一笔钱，要抵他好几张单 | 按「先老后新」自动抵，多出来的钱记成**预收** |
| **核销** | **这笔钱收不回来了**（客户跑了、对方免了） | 账上标记「不用再收」，**不算收到钱**、不进现金流 |

> 🔴 **最常见的错误**：客户给钱了，却点了「＋ 记一笔应收」。
> 结果账上变成「他又下了一单」，欠款越记越多。**收到钱只走「收款 / 收清 / 整户收款」。**

**钱给少了怎么办？**（实报实销，本来就会差几块几十块）

在「收款」的输入框里直接打 **`结清`**（或 `抹零`）两个字 → 差额记成核销，这张单结清，界面上写「已核销 X 元」。

> 核销的意思是「这笔不用再收了」，不是收到钱。所以它不会进银行流水，也不会算成收入。

**钱给多了怎么办？** 也直接填实际金额。多出来的部分系统自动记成**预收**，下次开单可以「预收抵」。

### 动线 C：花钱（支出 / 报销 / 发工资 / 买料）

点 **记账 → 支出**：

- **日常开销**（电费、运费、修机器、买辅料）：选分类 → 填金额 → 「记支出」。分类记得选对，月报靠它分组。
- **发工资**：分类选「工资」，或直接点上面那个 **「发工资（按实发数）」** 小按钮，它会帮你把备注填好「2026-11 工资（实发）」，你只填总数。
- **员工借支**：下面「员工借支 / 报销」区，填员工名 + 金额 → 「借出」。他报销时点那一行的「报销」，选分类填金额 → 这笔才进成本。
- **买料、外发加工费**：不要记在「支出」里！记在 **记账 → 应付**，因为这是**欠着**的钱（供应商月结），不是当场付的现金。等真付了再点「付款」。

> 一句话分界线：**当场掏钱的 → 支出；先欠着后付的 → 应付。**

## 三、几个容易搞混的专门场景

### 1. 付房东：租金要摊，押金不摊

记账 → 导入 → **付房东（租金/押金/水电）**：

| 名称 | 金额 | 月数 | 分类 |
|---|---|---|---|
| 厂房租金（3 个月） | 36000 | **3** | 厂房租金 |
| 押金 | 20000 | **0** | 押金 |
| 宿舍水电 | 1200 | 1 | 水费 / 电费 |

- **月数填 3** = 这 36000 分 3 个月摊进成本，不当月全算。
- **月数填 0** = 押金，钱挂在那里，退租时收回，**永远不进成本**。

### 2. 宿舍水电从工资里扣

（前提：功能模块里「计件工资」是打开的）

家底 → 工资 → **💧 扣宿舍水电**：填员工（多人用逗号隔开）+ 每人扣多少。

- **应发不变**，只是「实发 = 应发 − 扣款」。
- 扣款**不产生现金流水**（钱本来就没经过员工的手，直接给了房东）。

### 3. 含税不含税

**不用拆税。** 对方说多少就记多少（含税就按含税总额记），税率写在备注里就行。
这套账是**收付实现制**：收到多少算多少，付出多少算多少。

### 4. 押金、借支算不算「家底」？

**不算。** 家底 = 手头现金 + 别人欠我 − 我欠别人 − 借款。
押金要退回、借支会报销冲掉、预付是还没花掉的成本——算进去反而看不出真实家底。它们各自单独列一行。

## 四、月底：30 分钟收尾

### 第 1 步：把该收的收一遍

工作台 → **今天要做的事** → 该催的点「催款清单」，它会生成一段话术，直接复制发微信。

### 第 2 步：跟客户/供应商对一次账

记账 → 应收 → 客户那行点 **「对账单」**（整月的点 **「月结」**）→ 生成链接，发微信给对方。
对方看到的是**只读**的、只有他自己那几笔。

对方回的数和你的不一样？用 导入 → **对账（对方的余额）** 传进来，系统会并排列出「单上 X / 我这 Y」，差异可以一键 **＋ 补记这笔** 或 **✂ 核销差额**。

### 第 3 步：报表 → 月底收尾

报表 → **🗓 月底收尾（一屏看完）**：七步清单，做完的打勾，没做的写着「去办 ›」，点一下就跳过去。

### 第 4 步：结转归档（结账）

报表 → 填月份（如 `2026-11`）→ **结转归档（出报表 + 锁定）**。

> 🔒 结完之后这个月**不许再增删改**。要改就去报表页归档区点 **🔓 解锁（删归档）**，改完重新结一次。
> 所以结账前先看一眼那份七步清单是不是都做完了。

### 第 5 步：备份（每月一次，点一下就好）

**报表** → 往下滑 → **云端备份**。其实系统**每天自动备份一次**，你点一下只是多存一份「主动备份」。
备份只防「误删、停机、想搬家」，**换手机不用备份**——新手机装好小程序、输同一个口令，账就在云上。

## 五、一页速查表（可以打印贴墙上）

```
【每天】
  收到客户钱        → 💰 收钱 → 找到那张单 → 「收款」/「收清」
  当场花的钱        → 记一笔支出（分类别选错）
  客户/供应商对账数  → 记账 → 导入 → 「应收对账」/「应付对账」→ 下 → 填 → 传
  有人送货先欠着    → 记账 → 应付（不要记支出）
  收不回来的钱      → 单子上点「核销」（不算收到钱）

【收钱四件事，别点错】
  收款 = 收一部分（可填「3000,07-05」）
  收清 = 这单一次收完
  整户收款 = 一笔钱抵他好几张单，多的转预收
  核销 = 这笔不要了，不进现金流
  差几块钱收不齐    → 收款框里打「结清」

【每月】
  催款清单 → 生成话术 → 发微信
  对账单 → 发链接给客户
  报表 → 月底收尾（七步）→ 结转归档 → 云端备份
```

## 六、出问题了怎么办

| 你遇到的问题 | 怎么办 |
|---|---|
| **记错了金额** | 单子上点「改」，选改哪一项（客户/产品/金额/成本），一项一项改，改完会提示改了什么 |
| **多记了一张单** | 单子上点「删」。删错的在 **报表 → 回收站**，**30 天内能找回** |
| **收款记错了** | 明细里删掉那笔流水，单据的「已收」会自动退回 |
| **忘了口令** | **报表 → 🔑 找回口令 / 看恢复码** → 输入纸上那 16 位恢复码 + 新口令 |
| **员工也能看到钱吗** | 不能。**报表 → 👤 员工账号（一人一个口令）** 开号；员工进去看得到单、收得到钱，但看不到单价/毛利/外协费这类金额，删改单据、看报表、改设置都要老板口令 |
| **页面显示「有些数据没拉出来」** | 网不好。点那行字重试一次，不用杀进程重进 |
| **数字看着不对** | **报表 → 数据体检**（点「🩺 体检一下」）。100 分不用管；哪项有数字，后面写着去哪个页面补 |
| **系统说「这个月已结账锁定」** | 报表页归档区点 **🔓 解锁（删归档）** → 改完 → 重新结转一次 |
| **想关掉某个用不上的功能** | **报表 → 🧩 功能模块**。关掉的只是界面，数据一条不删 |

## 七、别做这四件事（新手最容易踩）

1. **别把「收到的钱」记成「新开的单」**。收到钱走「收款」，开出新活才走「＋ 记一笔应收」。
2. **别一笔一笔凑对账单**。对方给你一个总数，就按总数一条导进去；凑单据是审计思路，不是小厂日常。
3. **别在结完账的月份改东西**。系统会拦住你，硬要改先解锁，改完记得重新结。
4. **别把口令和恢复码发群里**。恢复码能重设口令，等于钥匙。

## 附：系统叫法 vs 厂里叫法

| 厂里怎么说 | 系统里叫什么 |
|---|---|
| 接的单、做的活、加工费 | 应收（一张单一条） |
| 硫酸、染料、外发加工费、月结的料款 | 应付（带「分类」） |
| 收到的钱 | 收款 / 整户收款 |
| 这笔不要了、让了、抹零 | 核销 |
| 对方给我的对账数 | 对账 / 月度对账（应收对账、应付对账模板） |
| 手里有多少钱 | 家底 / 账户余额 |
| 这个月赚了多少 | 报表 → 利润表 |
