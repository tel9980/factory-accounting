## 第 0 章 打开它

### 0.1 手机上怎么进

微信里搜小程序 → 打开。第一次进来会看到一张卡片，写「访问口令」。三种情况的走法：

| 你是什么情况 | 点哪里 |
|---|---|
| **第一次用，还没有口令** | 直接输一个新口令（至少 4 位，自己想一个）→「进入」 |
| **已经有口令了**（换手机、别人给你开的号） | 输入口令 →「进入」 |
| **只是想看看它长什么样** | 点 **👀 先看看演示（不用口令，示例数据）** |

**演示模式**是个沙箱：里面有几家示例客户、几张单、几笔支出，随便点、随便试记，**动不到你真账本一个字**。但演示里不能导出、不能备份、不能改设置。

### 0.2 设完口令，第一件事是抄恢复码

第一次设口令后，会弹出 **16 位恢复码**，长得像 `PH4D-LWDJ-WLPL-KG4H`。

> ⚠️ **立刻抄在纸上，贴在抽屉里。** 只显示一次，系统后台也不存。
> 忘了口令只能靠它重设；没有它，谁也进不去（连我们都救不了）。

以后想看它：**报表 → 往下滑 → 🔑 找回口令 / 看恢复码**。

### 0.3 认清屏幕：四个大页签

顶上四个大字就是全部骨架：

| 顶上一排 | 里面是什么 | 多久用一次 |
|---|---|---|
| **工作台** | 今天要做的事、四个大数字、钱够不够、一句话记账、🔎 找功能 | 每天开手机先看这里 |
| **记账** | 应收 / 应付 / 支出 / 导入（四个小页签） | 每天，记东西都在这里 |
| **报表** | 利润表、家底、历史、流水；**往下滑还有**：数据体检、导出 Excel、云端备份、🔑 找回口令、功能模块、员工账号、月底收尾、回收站、操作日志 | 每月一次，和偶尔要「管一管」的时候 |
| **设置** | 单位（账期 / 档案 / 合同价）、账户与期初、分类、账套、开账向导、账本封存 | 第一次用，之后很少 |

> 记住一句话：**「记账」里填数，「报表」里看数和管系统，「设置」里配单位和账户。**
>
> 🔎 **找不到按钮时**：回工作台，点 **🔎 找功能**，输两个字（如「备份」「体检」「核销」），点一下直接跳过去。

## 第 1 章 账套：你有三本账（最多能开到 9 本）

### 1.1 什么是账套

**一套独立的账。** 数据完全分开：A 账套记的单、收的钱、建的客户，B 账套里一条都看不到。

什么情况用得上：

- 两个厂 / 两个车间**分开算盈亏**；
- 一个厂做自己的账，另一个账套专门用来**试算、试新规则**；
- 帮亲戚朋友也记一份（各自的口令也可以不同）。

只做一个厂？**只用「主账套」就行**，另外两本空着不用管。

### 1.2 怎么切换、怎么改名

- **切换**：点屏幕最上面那行 **「当前账套：主账套（点此切换 / 改名）」** → 选另一本 → 确认「数据完全分开」。
- **改名**：同一行点进去，输入框写「一车间」→「改当前账套名」。
- 想看每本账有多少单：**设置 → 账套** 那一区，每本一行写着各自的单数。

### 1.2.1 手机上不方便设置？在电脑上弄

电脑打开 `…/pc` → 拉到第 6 块 **「账套（可以开几本 / 改名字）」** → 「看我的账套」：

- 一眼看到每本账的**名字、单数、应收、有没有设口令、有没有封存**；
- 点「改名」直接改，**不用先切过去**；
- 点「用这本」就把这一页切到那本（下面几块的下载、上传、导出、初始化、报表都跟着切）。

> 每本账的**口令是分开的**。切到另一本之后，如果它有自己的口令，要在第 1 块重新填一次再点「记住」（这台电脑会按账套分别记住）。
> 仓库里默认开 3 本；要多开一本得让懂电脑的人建一个新数据库（见 `DEPLOYMENT.md` 4.12），最多 9 本。

> ⚠️ 切换账套之后**看到的数字全变了**，不是数据丢了。看错了先抬头看最上面那行写的是哪本。

### 1.2.2 超级管理员 / 每本账自己的管理员

三种口令，别混：

- **主账套口令**（你最早设的那个）：进**所有**账套都是老板权限。
- **超级口令**（可选，至少 6 位）：也是进所有账套，另外还能**给别的账套设管理员口令**。适合「所有账都要管的人」。
- **某本账自己的管理员口令**：只能进那一本。适合「二厂的人只管二厂的账，别看到一厂」。

怎么设（在电脑上最简单）：`…/pc` → 拉到第 6 块 → 「6.1 超级管理员」填一个 6 位以上的口令保存；再点「看我的账套」，表格里每行点「设管理员口令」，给那一本设一个。

> 记住两条：①主账套口令**永远能进所有账**（老板不用记三把）；②想让某本账真正独立，就别把那把主口令告诉用那本账的人。

### 1.2.3 在电脑上加员工、给权限

厂里不止你一个人记账时，给每个人开一个**员工账号**（4 位口令）。手机小程序「设置 → 员工账号」能加，但**电脑上更快**：`…/pc` → 第 7 块「人员与权限」。

怎么加：

1. 「7.1 加一个人」填名字（如「小王」），口令留空就自动生成 4 位；
2. 勾上他要用到的模块（**应收**开单收款、**应付**进货付款、**支出与流水**、**批量导入**、**单位与对账**、**家底**）；
3. 点「加这个员工」，**口令只显示这一次**，抄下来给他。

之后在表格里随时：**换口令**（他忘了就点这个）、**改权限**（多给或少给几块）、**停用**（人走了先停用，账不动）、**删**。

两个总开关（勾上点「保存这两项」）：

- **员工只能看自己录的单**：默认关。开了之后他只看得到自己录的应收/应付，汇总报表还是整本账。
- **员工只能看自己负责的客户**：默认关。开了之后要先在「设置 → 把客户分给员工」里分谁负责谁，没分的客户他看不到。

> 员工**永远**不能删改单据、看不到毛利和金额类分析——这是代码挡的，不是靠勾选。
> 员工**按账套分开**：第 7 块列的是「现在这本账」的人。要在二厂加人，先把上面的账套切到第 2 本，再加一次。同一串口令在两本账里各是各的人（各记各的名字），别把同一个口令当成「谁都能进」。

### 1.3 什么时候该「封存」

老账本对完账、不想再被动到：**设置 → 🔒 账本封存 → 封存这本账**。

封存后整本**只能看不能增删改**（要改先解封，解封会留痕）。三本账各自单独封。

## 第 2 章 初始化：5 分钟把底数填好

> 初始化 = 告诉系统「**今天开始记账之前，手上是什么状态**」。
> 只需做一次。做错了可以回来重填（余额是「设」不是「加」，填两次不会翻倍）。

### 2.1 先看初始化清单

首页上面有张卡片 **「开账引导（照着填几步就能用）」**，四个小格，做完的打勾：

1. 填一下账户余额
2. 设个默认账期
3. 录「别人还欠我」的账
4. 录「我还欠别人」的账

两种填法，**挑一种，别两边都填**。

### 2.2 填法 A：一屏填完（30 秒，推荐）

点卡片上的 **⚡ 一屏填完（推荐，30 秒）**，弹出四块，一次提交：

| 填什么 | 填多少 | 备注 |
|---|---|---|
| **账户余额** | 现金 3000、银行卡 20000、微信 500… | 填「**现在剩多少**」，不是这月的流水 |
| **默认账期** | 一般 `30` | 开单后 30 天该收钱；填了以后开单不用再写收款日 |
| **期初应收** | 一行一家：`张老板 12000` | 别人现在**欠我**多少 |
| **期初应付** | `某某化工厂 8600` | 我现在**欠别人**多少 |

- 一行一家，`空格`、`逗号`、`Tab`、`冒号` 分隔都认，也能写 `5000元`。
- 填完点 **「保存，开始记账」**。
- 只有期初应收、没有期初应付？空着就行，不填的格子跳过。

### 2.3 填法 B：开账全套模板（客户多、想留底就用这个）

**记账 → 导入 → 📦 两个模板包 → 开账全套（8 页签）→ 点「下」**，
得到一个 Excel，第一页是说明，后面 7 页是数据：

| 页签 | 填什么 |
|---|---|
| 说明（第一页） | 不用填，看说明 |
| 账户期初 | 账户名 + 期初余额（不存在的账户会自动建） |
| 默认账期 | 天数，填 `30` |
| 客户名单 | 名称 + 客户/供应商（**只建档案，不建单、不动钱**）—— 70 多家先一次进来 |
| 期初应收 | 客户 + 金额，一家一行（**名字已经帮你填好了**） |
| 期初应付 | 供应商 + 金额 |
| 期初借支 | 员工 + 没还的金额（不进现金流水，只是记着） |
| 期初借款 | 出借方 + 本金 + 年利率 + 起始日 |

填完点那一行的 **「传」**，一次上传，**按页签名自己分发**到对应的地方。
没填的页签会显示「没填，跳过」，不会报错。

**客户多（几十上百家）分两步**：①先只把名字导进来——「客户名单」页填 70 多个名称（按客户的写「客户」，供应商写「供应商」），它**只建档案、不建单、不动钱**，欠款以后再按对账慢慢补；②这个月跟谁对完账，就把金额填到「应收对账 / 应付对账」里再导一次。

**都在电脑上填最省事**：手机上点模板中心那行「**电脑上填更省事 → 点这里复制网址**」，
把网址发到电脑浏览器打开 → 填一次口令 → 下载模板（**客户名已预填**）→ Excel 填金额 → 传回来。
详见 4.1。

### 2.4 分类和账户：不用手建

新账本默认已经有：

- **支出分类**：工资、水电、房租、采购、辅料、运费、维修、税金、其他
- **收入分类**：加工费、维修、其他
- **账户**：现金、银行卡、微信、支付宝（期初都是 0，等你填）

想一次配成某种厂的样子：**设置 → 🧱 新账本模板（空账本一次配好）**，四种挑一个：

| 模板 | 适合谁 | 建了哪些 |
|---|---|---|
| **生产加工（最常见）** | 接单做加工的厂 | 10 个支出分类 + 2 个收入分类 + 2 个账户，账期 30 天 |
| **只管流水（最简单）** | 只想记进出、不想管欠款 | 5 个分类 + 2 个账户，不设账期 |
| **只管应收** | 只关心客户欠我多少 | 3 个分类 + 1 个账户，账期 15 天 |
| **什么都记（含设备借款）** | 连设备、借款都要管 | 14 个分类 + 4 个账户，账期 30 天 |

> 只补缺的，不会覆盖你已有的分类和账户。

### 2.5 把用不上的关掉（界面立刻清爽）

**报表 → 往下滑 → 🧩 功能模块（用不上的关掉）**。

比如不按件算工资，就关「计件工资」（它默认就是关的）——少一半按钮，也不容易误点。
关掉只是藏界面，**数据一条不删**；哪天要用，再打开就回来了。

> 应收、应付、支出、Excel 导入这四块是地基，关不掉。

### 2.6 要用的人多的话（可选）

**报表 → 👤 员工账号（一人一个口令）**：一行一个人，勾上他能看的模块。

- 员工用自己的口令进来，只看到自己该看的；
- **看不到金额类的东西**（单价、毛利、外协费、返工损失这些只有老板能看）；
- 能记账、能收款，但**改单、删单、看报表、改设置要老板口令**；
- 员工按自己开的口令进去，能记账也能看「我今天干了啥」。

## 第 3 章 初始化完，先自检三件事

### 3.1 体检一下

**报表 → 数据体检 → 🩺 体检一下**。

一个新开的账本应该是 **100 分、没有红字**。有红字也不用慌，每条后面都写着「去哪个页面补」。

每天系统自己也会体检，有问题记在「运行日志」里。

### 3.2 试记一笔、再删掉

熟悉手感最有效：

1. **工作台 → ＋ 记一笔应收**：客户随便写「测试客户」、金额 100 → 记一笔
2. **记账 → 应收**：找到这一行，点「明细」，看看长什么样
3. 点行上的 **「删」**，删掉，去 **报表 → 回收站** 里也能看到它

### 3.3 马上主动备份一次

**报表 → 云端备份**。平时系统**每天自动备份一次**，你点一下只是额外多存一份。

> 备份只防「误删、停机、想搬家」，**换手机不用备份**（见 7.1）。

## 第 4 章 每天怎么用（三条动线）

> **一个人管账，只维护两本表。**
>
> | 哪本 | 什么时候用 | 里面有哪些页签 |
> |---|---|---|
> | **📦 开账全套** | 只有**新建账套**时填一次 | 账户期初 · 默认账期 · 期初应收 · 期初应付 · 期初借支 · 期初借款 |
> | **📦 日常台账** | **每天/每几天**填一次，一次传完 | 应收对账 · 应付对账 · 支出 · 借支 · 报销 · 付房东 |
>
> 都在 **记账 → 导入** 最上面：「下」下载空表，「传」上传填好的。
> 日常那本**空着的页签不用管**（会显示「没填，跳过」），所以做法是：
> 每天早上打开同一个文件，把昨天发生的事填到对应页签，攒够一次上传——不用一个个选类型、一个个传。

### 4.1 动线 A：照对方的对账金额导进来（最重要）

客户、供应商会给你一个数：「这个月你欠我 8600」。**不要一笔笔凑**，直接导。

1. **记账 → 导入**
2. 选页签：应收用 **应收对账**，应付/外发用 **应付对账**
3. 一行一家：客户名 + 对账金额（月份可空，空着算当月）
4. 点「传」

**客户多就在电脑上做（推荐）**：

- 手机：**记账 → 导入 → 📦 两个模板包 → 那行「电脑上填更省事 → 点这里复制网址」**
- 电脑浏览器打开这个网址（`…/pc`）→ 填一次口令（记在这台电脑）→ 下载模板 → Excel 填 → **先看看要导什么**（预览）→ **确认导入**
- 下载时**客户 / 供应商名字已经预填好**，你只对着名字敲金额；没敲金额的行会自己跳过，不报错。
- **员工名、经手人、分类也都是下拉**：借支、报销页的「员工」列，支出页的「经手人」列，点格子右边的小箭头就能选，不用手打。名字打错一个字，这笔就对不上人——他的借支余额、「只看自己录的单」全靠这个字。
- **预览会说清每一行错在哪**：不再只告诉你前 3 行。写错的、像重复的、撞上已结账月份的，分三类逐行列出（前 200 行），照着改就行。
- **传之前就能看到「导完会怎样」**：点「先看看要导什么」，除了告诉你哪几行导不进去，还会算一遍
  「这批进去之后：现金 1.28 万 → 2.14 万、应收 12.8 万 → 11.94 万」。要是它说「现金会变成负数」，
  那就是金额多打了个零，趁没导进去先改。**这只是试算，还没写库**。
- **传错了能整批退回来**：导入记录里点「撤回这批」，这一批进来的全撤掉，一分不留。报销撤回会顺手把员工借支的「已用」退回去；付房东撤回会把摊出去的租金一起删掉。已经结账的月份不许撤（那个月的报表已经出了）。

**统一规则**：一家一行、页签名别改、月份可留空、导过的同一份文件不会重复入账（改过内容就是新文件）。

**表大也不怕**：超过 1MB 的表手机上会自动**切成几片传**，进度条走完才算传好；万一半路断了，**再点一次会从没传完的那片接着传**，不会从头再来、也不会因此导两遍。真要传几十年的流水（几十 MB），还是用电脑上的 `…/pc`。

### 4.2 动线 B：收钱

客户给钱了，走 **💰 收钱**（工作台）或进单据点「收款」。

| 你要做什么 | 点哪个 |
|---|---|
| 收一部分 | 「收款」，输入金额；也能写成 `3000,07-05`（金额,日期） |
| 一次收完 | 行上的「收清」 |
| 一笔钱抵他好几张单 | 应收页的「整户收款」，多的自动转 **预收**，以后开单能「预收抵」 |
| 差几块钱收不齐 | 收款框里打 **「结清」**，差额记成核销（不算收到钱） |
| 这笔不要了 | 行上「核销」（不算收到钱，只是这笔不用再收了） |
| 多给了 | 直接填实际金额，多出的自动记预收 |

收款面板里还能顺手标：账户、`有票/没票`、税额、税点另收多少（见 5.3）。

**记单时顺手选一下「这笔钱是」。** 录应收的金额下面有一排：货款 / 加工费 / 打样费 / 模具费 /
运费代垫 / 包装代垫 / 维修费 —— 点一下选中，再点一下取消，不选也能记账。
为什么要选：月底看「应收」页顶部那张分类卡，就能知道这个月**卖货收了多少、来料加工收了多少**，
两种生意的毛利完全不一样，混在一起看会误判。电脑上填表时，模板第 5 列就是它（有下拉）。

### 4.2.1 别把「收到钱」记成「又开一张单」

这是最容易犯、也最不容易发现的一个错。

**「一句话记账」那一栏写「收张老板5000」，系统做的是「又给张老板开了一张 5000 的单」，
不是「收到他 5000」**——结果客户欠款不是少了 5000，而是多了 5000。

现在它会当场说清：「新开一张应收单：张老板 5000 元（欠款变成 12000）」；如果张老板原来就欠着钱，
还会多一句提醒「如果你是想记收到的钱，请点开那张单点「💰 收钱」」。

| 你心里的意思 | 该点哪里 |
|---|---|
| 又接了一单活，先记下来 | 一句话记账 / 「＋应收」都行 |
| 客户把钱给我了 | 进「应收」找到那张单 → **💰 收钱**（或行上的「收清」） |
| 客户一次性还了几张单 | 应收页 →「整户收款」 |

### 4.3 动线 C：花钱

**记账 → 支出**：

- **日常开销**（电费、运费、修机器、买辅料）：选分类 → 填金额 → 「记支出」。分类要选对，月报靠它分组。
- **发工资**：分类选「工资」，或点上面的 **「发工资（按实发数）」** 小按钮，它把备注填好「2026-11 工资（实发）」，你只填总数。
- **员工借支**：下面「员工借支 / 报销」区 → 填员工 + 金额 → 「借出」；他报销时点那一行「报销」→ 选分类填金额，这笔才进成本。
- **买料、外发加工费**：不要记「支出」！记 **应付**（先欠着后付的钱），真付了再点「付款」。

> 一句话分界线：**当场掏钱的 → 支出；先欠着后付的 → 应付。**

### 4.3.1 导表的时候，日期那一列别空着

补录上个月的纸质单，最容易整列忘填日期。以前日期空着就全记成**今天**，
于是账全进了本月，而「那个月已经结账、不许再改」这道锁也拦不住（它按日期判）。

现在预览会数出来：「有 3 行没写日期，会记成今天」。看到这句，**先去表里把日期补齐再传**；
如果你确实想记今天，那就照传，不拦你。

### 4.4 两个人同时点，会不会记两遍？

不会。你和会计同时点「收清」、手机上连点两下、电脑网页和小程序同时提交同一份表，
最后都只记一笔：第二个人的那一下会看到「这笔刚被别人动过，刷新再看一眼」，或者干脆显示
「这笔刚记过了」（那就说明已经记上了，不用再点）。

**同一份表，两个窗口同时点「导入」，也只会进一次。** 第二下会直接说「这份表已经导过了」。
（改过内容再传就是新文件，照常导。）

**用预收/预付抵扣、退借支余款的时候**，如果两个人几乎同时点，只有一个人的会生效；
另一边的流水不会偷偷多记一条——这一点专门写进回归测试盯着（`scripts/test-concurrency.mjs`，
67 项），因为这种错在屏幕上一点痕迹都没有，只有月底对账才发现钱多出来了。

万一真出现「同一个数对不上」，先做两件事：**点一下页面刷新**（可能只是屏幕没跟上），
然后**报表 → 🩺 数据自检**（它会直接告诉你哪张单、哪笔流水不对）。

**网不好的时候记的账，不会丢。** 断网（或信号一格）时记的每一笔会先存在手机上，屏幕顶上会出现
「待补 N 笔」；网一回来它自己按顺序补上去，补上了会提示「补上了 N 笔」。

几种情况你要知道怎么办：

| 你看到的 | 意思 | 你该做什么 |
|---|---|---|
| 顶上「待补 N 笔」一直不消 | 网还没好，或者服务端还没醒 | 等一下，或下拉刷新一次；点「待补 N 笔」可以手动重发 |
| 「有 1 笔没补上 · 这个客户两分钟内已经记过同样金额的单」 | 这一笔被规则挡回来了，**没有记进账** | 它留在「待补」里。先去对一下是不是真的记过了；确认要记就改一下金额/客户再记 |
| 「口令过期了，重新输一下；剩下的 N 笔会自动补发」 | 只是要重新登录，账没丢 | 输口令就行，剩下的会自动接着补 |
| 某一笔永远发不出去（比如那张单你已经删了） | 它再也补不上了 | 点「待补 N 笔」→「先不发」→ 它会问「最早那笔要不要丢掉」→ 确认丢掉 |

## 第 5 章 四个容易搞混的场景

### 5.1 付房东：租金要摊，押金不摊

**记账 → 导入 → 付房东（租金/押金/水电）**：

| 名称 | 金额 | 月数 | 分类 |
|---|---|---|---|
| 厂房租金（3 个月） | 36000 | **3** | 厂房租金 |
| 押金 | 20000 | **0** | 押金 |
| 宿舍水电 | 1200 | 1 | 水费 / 电费 |

- **月数 3** = 36000 分 3 个月摊进成本，不当月全算。
- **月数 0** = 押金，钱挂在那儿，退租时收回，**永远不进成本**。

### 5.2 宿舍水电从工资里扣

（前提：功能模块里「计件工资」是打开的）

**家底 → 工资 → 💧 扣宿舍水电**：填员工（多人用逗号隔开）+ 每人扣多少。

- **应发不变**，只是「实发 = 应发 − 扣款」。
- 扣款**不产生现金流水**（钱本来就没经过员工的手，直接给了房东）。

### 5.3 含税不含税、有票没票、税金另外收

**利润按实收实付算，不拆税**（这套账是收付实现制）。但「税」和「票」都记得下，四句话：

**① 开单时说一句这单是含税价还是不含税价。**
金额下面有三个小按钮 `含税` `不含税` `不标` + 税率框。税率自己填（13/9/6/3/1 都行——税率不固定），填完直接算出「税额 ¥130，不含税 ¥1000」。

- 票面税额跟算出来的差几分？别填税率，**直接填税额**。
- 懒得标就选「不标」，当作没有税，**不影响欠款计算**。

**② 收付款时说一句这笔有没有票。**
收款面板里有：金额、日期、账户、`有票` `没票` `部分开票`、税额。

- **选账户自动带出习惯**：工行对公户一般有票、农行个人户一般没票。在 **设置 → 单位 · 账户 → 点「平时有无票」** 设一次，以后不用每次想。
- 为什么等收付才标？因为有些票要等实际收付才知道有没有，所以**票记在这笔钱上，不记在单据上**。

**③ 最常用的一条：开票就另外收税点，不开票只收货款。**
「货款 1000」的实际做法：

- **不开票** → 收 1000，选 `没票`，税点框清空，完事。
- **开票** → 货款还是 1000，**另外收税点**（可能是 100）。选 `有票`，系统按税率自动把税点填进「税点另收多少」，确认一次就同时记好：货款 1000 冲这张单、税点 100 单独一笔。
- 税点那笔**不算收入**（代收的，回头要交出去），但**钱在账上**，余额照算。

**④ 税金另外给的，要勾一下。**
货款 1000 只收了 800、税 130 另外转过来：面板里勾 **「这是另外收付的税金，不冲这张单」**——系统单独记一笔「税金」，**这张单的欠款一分不动**。不勾的话，130 会被当成货款，这张单就被提前算成收齐了。

**月底看一眼：报表 → 💰 本月税金** ——收了多少税、付了多少税、大概要交多少，还有**多少笔支出没票**（没票不能抵税，最容易吃亏的地方）。

速记：**欠款只看金额；票和税只影响「税金」那一块统计。**

### 5.4 押金、借支算不算「家底」

**不算。** 家底 = 手头现金 + 别人欠我 − 我欠别人 − 借款。
押金要退回、借支会报销冲掉、预付是还没花掉的成本——算进去反而看不出真实家底，它们各自单独列一行。

## 第 6 章 月底：30 分钟收尾

### 6.1 把该收的收一遍

**工作台 → 今天要做的事** → 该催的点「催款清单」，生成一段话术，复制发微信。

### 6.2 跟客户/供应商对一次账

**记账 → 应收 → 客户那行「对账单」**（整月的点「月结」）→ 生成链接发微信给对方。
对方看到的是**只读**、只有他自己那几笔。

对方回的数和你的不一样：**导入 → 对账（对方的余额）** 传进来，系统并排列出「单上 X / 我这 Y」，差异可一键 **＋ 补记这笔** 或 **✂ 核销差额**。

### 6.3 一屏看完七步

**报表 → 🗓 月底收尾（一屏看完）**，七步：本月单据录完 → 和客商对过账 → 差异处理完 → 对账单发给客商 → 出一页月度小结 → 备份一次 → 结账归档。做完的打勾，没做的写着「去办 ›」，点一下跳过去。

### 6.4 结转归档（结账）

**报表 → 填月份（如 `2026-11`）→ 结转归档（出报表 + 锁定）**。

> 🔒 结完之后这个月**不许再增删改**。要改先 **🔓 解锁（删归档）**，改完重新结一次。
> 所以结账前先看一眼那份七步清单是否都做完了。
> 收上个月的尾款**不受影响**（锁定是按「这笔钱哪天发生」算的，不是按单据月份）。

### 6.5 备份

**报表 → 云端备份**（每月点一次就够；系统每天也会自动备份）。

## 第 7 章 备份、换手机、找回口令、封存

### 7.1 换手机

**不用备份。** 新手机装好小程序 → 输同一个口令 → 账都在云上。

（口令只存在云上，不跟着手机走；所以千万别把口令告诉不相干的人。）

### 7.2 备份有三层

| 在哪 | 是什么 | 什么时候用 |
|---|---|---|
| 系统自动备份 | 每天一次，存最近 30 份 | 误删、手滑，去「报表 → 云端备份」挑一份恢复 |
| 云端备份（手动） | 你点一下多存一份 | 结账前、重要改动前 |
| 📦 整库备份 | 把整个库导出成一个文件 | 想换服务器、想自己留一份 |

恢复备份会**覆盖**当前数据，恢复前系统会自动存一份「恢复前快照」，反悔时能退回去。

> ⚠️ **切了账套别急着点「恢复」**：每本账的备份是各存各的（第 1 本的「第 3 份」和第 2 本的「第 3 份」是两份完全不同的账）。
> 切账套之后先退出去、重新进一次「报表 → 云端备份」，看清楚了再点。系统会发现「这份备份不是这本账的」并拦住你，
> 但自己看明白更省事。

### 7.3 忘了口令

**报表 → 🔑 找回口令 / 看恢复码** → 输入纸上那 16 位恢复码 + 新口令。

恢复码也丢了？那就只能找最近一次备份、或从 D1 时间点恢复（这部分是技术人员的事，写在 `DEPLOYMENT.md`）。

### 7.4 想给老账本「定版」

**设置 → 🔒 封存这本账**：整本只读，要改先解封（解封会留痕）。

### 7.5 换公司了，怎么重新用

三种做法，看你舍不舍得删：

| 情况 | 怎么做 |
|---|---|
| 两家公司都要记账 | 顶部「当前账套」切到**账套二**，各记各的（三本账互相看不见） |
| 老账想留着看、新公司从头记 | 电脑打开 `…/pc` → 第 4 块选账套 → 先「导出这本账」存个底，再「一键初始化」 |
| 只想给账本改个名 | 设置 → 账套 → 改名，数据不用动 |

「一键初始化」清掉的是**当前选中的那本账**：单据、流水、客户、材料、工资、备份、照片全清，账户和分类回到默认；**口令和账本名留着**；清空前自动备份一份，点错了还能从「报表 → 备份列表」退回去。

换电脑同理：老电脑 `/pc` 导出 JSON → 新电脑 `/pc` 导入。

### 7.6 想把报表存下来 / 打印

电脑打开 `…/pc` → 第 5 块「报表存档」，选一个类型、填日期，点「下载 Excel」：

| 要什么 | 选哪一项 |
|---|---|
| 今天收了多少、付了哪些 | 日报（某一天） |
| 这个月的利润表、应收应付明细 | 月报（某个月，一次 8 张表） |
| 今年 12 个月怎么样、年底还欠多少 | 年报（某一年） |
| 谁欠我钱、欠了多久 | 应收台账 |
| 我欠谁钱、欠了多久 | 应付台账 |
| 某个科目（工资、房租、货款…）的逐笔账 | 明细账（按科目） |
| 每个科目的期初 / 本期 / 期末 | 科目余额表 |

存下来的文件叫「月报_2026-11.xlsx」这种名字，直接发微信、打出来都行。**这些是给人看的**，恢复数据还是用第 7 章上面的「整账套」JSON。

| **换了手机看不到账** | 输同一个口令就行，不用备份 |

## 附三 别做这四件事

1. **别把「收到的钱」记成「新开的单」**。收钱走「收款」，开新活才走「＋ 记一笔应收」。
2. **别一笔一笔凑对账单**。对方给一个总数，就按总数一条导进去；凑单据是审计思路，不是小厂日常。
3. **别在结完账的月份改东西**。系统会拦；硬要改先解锁，改完记得重新结。
4. **别把口令和恢复码发群里**。恢复码能重设口令，等于钥匙。

## 附四 厂里叫法 vs 系统叫法

| 厂里怎么说 | 系统里叫什么 |
|---|---|
| 接的单、做的活、加工费 | 应收（一张单一条） |
| 硫酸、染料、外发加工费、月结的料款 | 应付（带「分类」） |
| 收到的钱 | 收款 / 整户收款 |
| 这笔不要了、让了、抹零 | 核销 |
| 对方给我的对账数 | 对账 / 月度对账（应收对账、应付对账模板） |
| 手里有多少钱 | 家底 / 账户余额 |
| 这个月赚了多少 | 报表 → 利润表 |
| 开票多收的那点钱 | 税点（税额另外收） |
