## 原始需求（未修改）

## 1. 目标
为小型加工工厂提供轻量化、私有化的记账与进度管理工具。

## 2. 核心数据表设计 (SQL)
- `orders` (订单表):
  - `id`: 主键
  - `customer`: 客户名称
  - `item_name`: 产品名称
  - `price`: 约定加工费
  - `status`: 状态 (0: 待加工, 1: 加工中, 2: 已交付)
  - `paid`: 已收金额
  - `created_at`: 创建时间

- `payments` (流水表) _（实际落地时改名成了 `ledger`，因为里面收和支是一张表、还有账户/分类/批次等列）_:
  - `id`: 主键
  - `order_id`: 关联订单
  - `amount`: 金额
  - `type`: 类型 (1: 收款, 2: 支出)
  - `remark`: 备注

## 3. 业务逻辑
- **加工费收入管理**: 录入订单 -> 记录加工费 -> 登记分批收款。
- **进度追踪**: 实时更新订单状态。
- **欠款统计**: 自动计算 `price - paid` 的欠款情况。

## 4. 技术栈
- **前端**: 微信小程序 (原生)
- **后端 API**: Cloudflare Workers (Hono 框架)
- **数据库**: Cloudflare D1
- **代码仓库**: GitHub (由 DSH 管理)
