# 小工厂记账财务小程序

面向**以收取加工费为主要收入**的小型工厂：记录应收（客户欠我）、应付（我欠供应商）、日常支出、批量导入、对账、报表与备份。**零服务器成本**，小白也能自己部署使用。

## 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | 微信小程序（原生） | 一个主页面 + 7 个功能页签，无需后端服务器 |
| 后端 | Cloudflare Workers（Hono） | 所有 API 跑在边缘节点，免费额度够用 |
| 数据库 | Cloudflare D1（SQLite），支持多账套（DB / DB2 / DB3） | 结构化存单、流水、口令、快照 |
| 托管 | GitHub | 代码托管，改完 `wrangler deploy` 即上线 |

## 功能清单

- **首页看板**：本月收 / 本月付 / 本月结余、客户欠我、我欠别人、经营毛利、手头现金合计
- **一句话记账**：输入「收张老板5000」「工资5000」「付王五金货款3000」自动识别入账
- **应收**：记订单（客户、产品、金额、约定收款日、经手人）、收款、交付、改、删、搜索、对账、月结
- **应付**：记应付单（供应商、金额、备注、经手人）、付款、改、删、对账、月结
- **支出**：六分类（工资/水电/房租/采购/辅料/其他）+ 现付支出 + 经手人
- **固定支出**：工资、房租等每月到号自动记一笔，可「立即补记本月」
- **批量导入**：从 Excel 复制多行粘贴导入，支持 应收 / 应付 / 支出 / 期初应收 / 期初应付，末尾可带日期
- **报表**：年度流水报表（按月/分类/应收应付汇总）、月度收付柱状图、导出 Excel（CSV）、复制报表
- **历史**：已结清的应收 / 应付
- **单位**：客户 / 供应商汇总，往来明细一键复制
- **资金账户**：现金 / 银行卡 / 微信 / 支付宝多口袋，各账户自动算余额，可加期初余额、改名、加新账户
- **预收款 / 预付款**：客户先给钱、供应商先收定金，先挂账，开单后可一键抵扣（只冲往来，不动现金）
- **防重复录入**：同一天同分类同金额的支出、7 天内同供应商同金额的应付，录入时弹窗确认一次，防手抖记两遍
- **自定义分类**：支出 / 收入分类可自己加删，报表与预算按分类统计
- **员工借支 / 报销**：借出钱给员工（不冲成本，只减现金）→ 报销时选分类冲借支（不动现金）→ 没花完可退回余款，未清借支合计一眼看到
- **坏账核销**：应收要不回来 / 供应商免了钱，可以「核销」一部分或全部，只抹往来不动现金；核销记录可查可撤销，净资产与应收统计自动扣掉核销部分
- **账户内部转账**：现金存银行、微信提现，两边账户余额同步变动，但不算收入也不算支出，不影响利润
- **提醒汇总**：首页把该管的事一次列清（逾期应收、7 天到期收付、预算超支、未认领流水、未清借支、未开发票）
- **发票台账**：开出发票 / 收到发票分开记（号码、对象、金额、税额、日期），本月开出收到和税额自动汇总，已收款未开票自动提示；只做台账不进收支，不重复算钱
- **固定资产折旧**：录设备原值/买入日期/年限/残值率，按直线法自动算月折旧、累计折旧、净值，可一键把本月折旧记成一笔支出（防重复）
- **银行流水对账**：粘贴银行卡/微信账单（日期,收/付,金额,摘要），一笔笔「抵应收 / 抵应付 / 记成一笔账」，带方向校验，不会把付款错抵成收款
- **导入模板导出**：每一类导入都能一键导出一份 CSV 模板，发到电脑用 Excel 填好、存 CSV UTF-8 再发回来导入
- **提醒**：逾期 30 天红条、7 天内到期黄条
- **操作日志**：记录每笔增删改、收付款、锁定等动作，报表页可查最近 100 条
- **备份**：一键全量备份（复制文本）、每日自动云端快照（保留 30 份）、自动同步到 Markdown 笔记站、一键恢复（粘贴备份文本，恢复前自动留快照）
- **访问口令**：首次使用自设口令，所有数据接口需口令访问，可改口令

## 快速开始

1. **后端**：`cd backend && npm install`，把 `wrangler.toml` 里的 `database_id` 换成你的 D1 库，执行 `schema.sql` 建表，再 `npx wrangler deploy`。
2. **前端**：微信开发者工具导入 `frontend` 目录，把 `frontend/pages/index/index.js` 顶部 `API_BASE` 改成你的 Worker 地址。
3. **上线**：微信公众平台把该域名加进 `request` 合法域名；本地调试勾选「不校验合法域名」。

详见 [`DEPLOYMENT.md`](./DEPLOYMENT.md)。

### 备份到笔记站（可选）

账本可自动同步为 Markdown 笔记，存到外部笔记站（本项目默认接一个 Workers + D1 的 Markdown 笔记服务，如 `https://md.1211.cc.cd`）：

```bash
npx wrangler secret put NOTES_PASS     # 笔记站的编辑口令
```

`wrangler.toml` 的 `[vars]` 里填 `NOTES_BASE`（笔记站地址）和 `NOTES_SLUG`（笔记 slug）。部署后，小程序「报表」页点「备份到笔记站」手动同步，Worker 每日 cron 也会自动同步一次。

## 数据模型

- `orders`：应收单（客户、产品、金额、状态、已收、约定收款日、经手人）
- `accounts`：资金账户（名称、类型、期初余额）
- `categories`：收支分类（支出类 / 收入类，可增删）
- `advances`：预收 / 预付（方向、对象、金额、已抵扣）
- `loans`：员工借支（员工、借出、已报销、已退回）
- `invoices`：发票台账（开出发票 / 收到发票）
- `assets`：固定资产（原值、买入日期、年限、残值率）
- `bank_flows`：银行流水（日期、收付、金额、摘要、是否已认领）
- `writeoffs`：坏账核销记录（应收核销 / 应付豁免、金额、原因）
- `transfers`：账户内部转账（转出账户、转入账户、金额）
- `payables`：应付单（供应商、金额、已付、分类、备注、经手人）
- `ledger`：收付流水（收/付方向，关联订单或应付，或现付支出；`account_id` 记哪个账户，`cash=0` 表示预收预付抵扣不动现金）
- `settings`：系统设置（访问口令）
- `backups`：每日云端快照（全量 JSON，保留 30 份）
- `fixed_expenses`：固定支出（金额、分类、每月几号记、备注）
- `month_lock`：月度结账锁定（锁定月份不可增删改）
- `audit_log`：操作日志（动作、对象、详情、时间）
- `budgets`：支出预算（分类、月度额度）
- `phrases`：常用短语（一句话记账常用语模板）
- `trash`：回收站（删除的单据与流水，保留 30 天）
- `process_log`：生产工序记录
- `process_log`：订单工序流水（订单、工序、经手人、时间）

## 说明

- 本项目为**个人记账工具**，不含发票、报税、银行对账等企业财务功能；需要正式财务软件请另选。
- 微信**个人主体**小程序无法开通微信支付，若后续要收款到小程序，需升级企业主体（约 300 元/年认证）。
